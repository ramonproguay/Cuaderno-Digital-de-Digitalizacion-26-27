# Encriptación

## ¿Para qué sirve la encriptación?

La encriptación sirve para proteger la información y evitar que otras personas puedan leerla sin permiso. Consiste en transformar un mensaje normal en un texto que no se entiende a simple vista. Para recuperar el mensaje original se necesita una clave o contraseña.

Se utiliza, por ejemplo, para proteger mensajes, archivos y datos personales cuando se guardan o se envían por Internet.

## Herramientas que he utilizado

### 1. Cifrar Online

[https://cifraronline.com/](https://cifraronline.com/)

Esta página permite escribir un texto y cifrarlo usando una contraseña.

Sirve para aprender cómo se protege un mensaje y cómo se puede recuperar después.

### 2. Herramienta RSA

[https://0x0bee.com/es-ES/tools/rsa](https://0x0bee.com/es-ES/tools/rsa)

Esta herramienta permite probar el cifrado RSA. RSA utiliza dos claves: una clave pública, que se puede compartir para cifrar mensajes, y una clave privada, que debe mantenerse en secreto y sirve para descifrarlos.

Sirve para comprender cómo se pueden enviar mensajes de forma que solo la persona que tiene la clave privada pueda leerlos.

### 3. Generador de hashes

[https://hashes.com/es/generate/hash](https://hashes.com/es/generate/hash)

Esta página transforma un texto en un código llamado hash. Permite generar distintos tipos, como MD5, SHA-1 y SHA-256.

Un hash no es lo mismo que un texto cifrado: normalmente no se puede recuperar el texto original a partir del hash. Se utiliza para comprobar información y para otros usos relacionados con la seguridad informática.
